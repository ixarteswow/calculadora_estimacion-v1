## Variables

| Variable | Dónde copiarla en el dashboard |
|---|---|
| `SUPABASE_URL` | Project Settings → API → Project URL |
| `SUPABASE_KEY` | Project Settings → API → **publishable** key (NUNCA la secret key) |
